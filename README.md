# Proyecto de Código: Grafos y Matriz de Adyacencia en Java (EDA - Sesión 09)

## Descripción
Modelado de una red logística de distribución y transporte mediante una matriz de adyacencia:
- **`GrafoMatriz.java`**: Estructura encapsulada con matriz bidimensional de enteros (`int[][]`), validación de rangos, inserción de aristas con pesos, consulta en $O(1)$ e impresión tabular.
- **`Main.java`**: Caso de prueba con 5 vértices que modelan sedes y rutas de la institución.

## Compilación y Ejecución

```powershell
# 1. Compilar clases al directorio bin
javac -d bin src/*.java

# 2. Ejecutar la clase principal
java -cp bin Main
```
